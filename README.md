# 💰 Smart Personal Finance & Budget Planner

A full-stack budgeting and personal finance management web application developed using **Python**, **Streamlit**, and **SQL**. Designed to help users effortlessly track daily expenses, manage budgets, and visualize financial health through interactive UI components and secure data storage.

---

## 🚀 Features

* **Expense & Income Tracking:** Easily log, categorize, and manage income streams and daily expenditures.
* **Interactive Dashboard:** Dynamic charts and visual breakdowns of spending habits powered by Streamlit.
* **Budget Management:** Set category-wise spending limits and monitor financial goals in real time.
* **Secure Data Storage:** Lightweight and reliable data management backed by SQLite/SQL database integration.

---

## 🛠️ Tech Stack

* **Frontend & UI:** Python, Streamlit
* **Backend Logic:** Python
* **Database:** SQL / SQLite (`budget_tracker.db`)
* **Development Tools:** Visual Studio Code, Git & GitHub
